# Benchmark samples

Two short recordings used by the installer to measure this machine before
choosing a backend and model size.

- `sample-lt.ogg`  Lithuanian, 60 s
- `sample-en.ogg`  English, 43 s

Both are the repository author reading a conversation aloud, recorded with the
capture half of this project. They exist so the installer can measure rather
than guess, and so the numbers it reports are comparable between machines.

They are deliberately clean, read speech in a quiet room, which is easier than
a lecture hall at ten metres. Treat the measured speed as an upper bound.
